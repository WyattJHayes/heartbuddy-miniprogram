## 口播录制注意事项
1. **S4 的“一个字、两个字”句**：录两版，一版正常语速，一版放慢强调，剪的时候挑情绪对的那版
2. S7/S9 情绪下沉、节奏放慢半拍，但**不要说教**，全程“陪伴感”
3. 全程声音发热（AirPods 或电容麦即可），降噪後导出 -23 LUFS
4. 口播 + 音乐叠底后核对：口播峰值 ≥ 音乐 10dB 以上（BGM −20dB）
