# 心语伴 · 评审答辩 Q&A 预判（10 问）

> 用于大赛答辩 / 评委提问环节。每条都结合本项目**实际实现**作答，练几遍即可对答如流。

---

## Q1 你们做的核心技术是什么？为什么选「小程序 + 云开发 + 大模型」这套组合？

- 核心不是"接一个大模型的聊天机器人"，而是**AI 多轮共情对话 + 情绪识别与可视化 + 危机安全分级**组成的闭环。
- 技术选型理由：
  - **微信小程序原生**：启动快、审核路径成熟，正好对口"小程序大赛"。
  - **云开发（CloudBase）**：云函数 + 云数据库免运维、冷启动秒级，天然复用微信登录体系，demo 成本最低，能跑起来给评委看。
  - **OpenAI 兼容接口**：一行配置换模型（DeepSeek / 混元等），不绑定厂商，也便于评委追问扩展性。

## Q2 AI 会一本正经地胡说八道（幻觉），你们怎么控制？

三招层层夹击：
1. **系统提示词约束**（`prompt.js`）：限定"情绪陪伴者"人设，明确不诊断、不治疗、不贴标签，回复要温和且不超过合理长度。
2. **上下文收口**：只传最近 10 条消息，避免长对话发散。
3. **结构化判定 + 本地兜底**：提示词要求危机检测输出 JSON；`danger.js` 再做一套本地关键词分级规则，两套结果合并取最高等级。判不准就**不触发、不下结论**——宁可少说，不可错说。

## Q3 心理健康类产品最怕出问题的是"风险"，你们的闭环是什么？

- **双保险识别**：LLM 输出 `{"crisis":true,"level":"high"}` + 本地规则分级（high / mid / low）。
- **分级响应**：高危 → 弹窗一键跳求助页；中危 → 温和引导；低危 → 不打扰，仅轻提一句。
- **兜底**：即使 LLM 请求失败，本地规则仍能返回求助提示；危机记录独立落库 `crisisAlerts`（只存时间与等级，不含聊天正文）。
- **全局声明**：首屏 + 周报 + 求助页都有"非医疗诊断"提示，求助页内置热线并可一键拨打。

## Q4 你收集用户隐私吗？数据安全怎么做？

- **对话正文不进数据库**：只用于当次会话，会话结束即失效。
- **三类最小必要数据**：情绪标签、自评得分、危机（时间 + 等级）——全部脱敏，无姓名/手机号/定位/通讯录。
- **知情同意**：进入先过《同意并开始》页，并有《用户须知与免责声明》《隐私政策》全文；后台只读「仅创建者可读写」，别人看不到你的数据。
- 密钥全部走云函数环境变量，代码库零密钥。

## Q5 市面上 AI 心理产品不少，你们差异化在哪？

- **细分**：不做"什么都聊"，绑定**考前焦虑**场景，做成「倾诉 → 情绪可视化 → 自评 → 周报/分享卡」完整的自我照顾闭环。
- **安全即卖点**：把"危机分级"做成能演给你看的界面（演示视频专门一段），这是多数 demo 没有的。
- **成本可控**：token 限额 + 提示词精简，云开发免费额度内即可支撑演示流量。

## Q6 你们评价"有用"的标准是什么？有评测吗？

- 对 demo 版本，我们设三类观测指标：
  1. **流程完成率**：自评完成、周报生成、一键求助的成功路径是否有 bug；
  2. **危机识别准确率**：人工复核每一条 `crisisAlerts`，统计命中/误报；
  3. **小样本体验访谈**：10 人左右真机使用后问卷 + 访谈，收集客观反馈。
- 上架前按此报告提交给评审（评分表"鲁棒性"一栏就靠它）。

## Q7 未成年人/合规红线？

- 不与 14 周岁以下单独提供服务；超过年龄需监护人同意（已写入《隐私政策》）。
- 不索取未成年人的身份证、定位等敏感性信息；如果风险提示高危，第一时间引导联系身边成年人/学校心理室。

## Q8 你们这个"对话像人"是怎么实现的？

- 中文学共情提示词 + 模拟**流式打字机**体验，让 AI 回复"先接住情绪、再给建议"。
- 多轮记忆最近 10 条；情绪由提示词回传的 JSON `mood` 字段驱动可视化，看起来像"它懂你"。
- 边界诚实：AI 是替代，不冒充真人；界面上有"非医疗"声明。

## Q9 接下来打算怎么扩展？

分三步：
1. **人机协作**：高危记录实时转给人工值守端（老师/咨询师台）排查；
2. **内容加厚**：考试倒计时、情绪日记模板、目标清单；
3. **商业化落地**：面向学校心理室 / 出版机构 / 公益组织的 B 端授权——这也是整个我们小组最现实的一条出路。

## Q10 一句话介绍你们产品？

> "心语伴——一个**先把安全底线做到底**的 AI 情绪陪伴小程序：考前焦虑细分、对话有温度、危机有兜底，隐私与合规边界内，从第一步就能跑给评委看的完整闭环。"
