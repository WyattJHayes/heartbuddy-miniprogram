# 心语伴 · 部署与运维手册

> 从零把一个微信小程序跑起来 + 日常运维。按顺序做即可（预计 30+ 分钟，不含大模型 Key 申请）。

## 0. 你需要准备
- 微信小程序账号（[mp.weixin.qq.com](https://mp.weixin.qq.com) 注册，个人主体即可参赛）
- **AppID**：登录后「开发 → 开发管理 → 开发设置」查看
- 微信开发者工具（稳定版，[下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)）
- 一个大模型 API Key（OpenAI 兼容格式均可：DeepSeek / 通义 / 智谱等）
- Node.js ≥ 14（局部校验用）

## 1. 导入项目
1. 开发者工具 → 「导入」→ 选择本项目 `heartbuddy-miniprogram/`
2. AppID 填自己的；若个人信息填「测试号」则云开发不可用，**必须用你的真 AppID**
3. 打开 `project.config.json`，确认 `"appid"` 已替换（自动生成需要 `compileType: miniprogram`）

## 2. 开通云开发
1. 工具左上角 「云开发」按钮 → 首次按提示开通
2. 创建**基础版环境**（免费额度：数据库 2GB / 云函数调用若干 / 存储）
3. 记录你的**环境 ID**，形如 `xx-xxxxxx`
4. 在 `app.js` 中确认 `wx.cloud.init({ traceUser: true })`（默认使用第一个环境）；若配置了多环境，把环境 ID 填进 `env` 字段

## 3. 创建数据库集合（5 个集合）
云开发控制台 → 数据库 → 新建集合，**名称必须完全一致**：

| 集合名 | 用途 | 权限建议 |
|---|---|---|
| `users` | 用户记录（login 写入） | 仅创建者可读写 |
| `moods` | 情绪标签 | 仅创建者可读写 |
| `assessments` | 自评得分 | 仅创建者可读写 |
| `crisisAlerts` | 危机预警（时间+等级） | 仅创建者可读写 |
| `feedbacks` | 意见反馈 | 仅创建者可读写 |

> 云函数默认走管理员权限，不受集合「权限设置」限制；所以用户手动写库用「仅创建者可读写」就能防串数据，运维读统计走云函数即可。

## 4. 上传云函数
对下面 **3 个**文件夹依次右键 → 「上传并部署：云端安装依赖」：

- `cloudfunctions/login/`  — 静默登录，写 `users`
- `cloudfunctions/aiChat/`  — 对话 + 情绪 + 危机（**必须在（安装依赖）**）
- `cloudfunctions/opsSummary/` — 运营统计（演示）

检查方法：云开发控制台 → 云函数 → 三个函数状态正常；点「云端测试」直接调用 `login` 应返回 `{ openid, ... }`。

## 5. 配置 aiChat 环境变量（关键！）
云开发控制台 → 云函数 → `aiChat` → 配置 → 环境变量，新增三个：

| 变量 | 示例 | 说明 |
|---|---|---|
| `LLM_API_KEY` | `sk-xxxx` | 你的大模型 Key（**不放进代码/仓库**） |
| `LLM_BASE_URL` | `https://api.deepseek.com/v1` | OpenAI 兼容端点，结尾带 `/v1` 更稳 |
| `LLM_MODEL` | `deepseek-chat` | 模型名，按服务商文档填 |

「保存并重启」后再「云端测试」：传 `{ action:'chat', messages:[{role:'user',content:'你好'}] }` 应返回 AI 回复；乱码/超时按文末「常见问题」排查。

> 读取失败会走**本地兜底**（`danger.js`），安全功能仍然可用，只是没有 AI 回复。

## 6. opsSummary 白名单
1. 先跑一次 `login` 云函数，把返回里的 **openid**
2. 打开 `cloudfunctions/opsSummary/index.js`，把 `ADMIN_OPENIDS` 里的 `''` 替换成你的 openid（多个用 `，逗号分隔字符串数组）
3. 重新上传该云函数

## 7. 真机验收（重要，出包前必做）
- 开发者工具「预览」生成二维码，手机微信扫码体验
- 重点测 3 条路径：
  1. 首屏同意 → 对话 → 发消息 → 收到回复 ✓
  2. 对话里输入危机敏感句 → 弹高危弹窗 → 一键去求助页 ✓
  3. 我的 → 运营看板（演示）能读到统计 ✓
- 再测：自评完成、周报生成 + 分享卡保存 / 转发

## 8. 上线（提交审核）
- 类目建议：**工具 → 健康管理**（避免医疗类目资质要求）
- 提交前按 `docs/参赛提交自查清单.md` 逐项核对：
  - 隐私（《隐私政策》页已有）+ 用户须知弹窗 ✓
  - 内容安全：建议额外接「微信内容安全检测」`security.msgSecCheck`（上架前必加，见下）
  - 热线号码复核：12356 / 400-161-9995 实际拨通确认
- 「上传」→ 版本描述填功能清单 → 提交审核

### 上架前必补：内容安全检测（msgSecCheck）
`aiChat` 云函数在消息入库/返回答复前调用
`cloud.openapi.security.msgSecCheck`（需先在控制台「开发-开发设置-服务内容安全」申请该接口权限），不合规直接拦截。这是小程序内容合规的硬要求。

## 9. 日常运维
| 事项 | 入口 |
|---|---|
| 查看危机预警 | 云开发控制台 → 数据库 → `crisisAlerts`（等级/时间 + 是否处理） |
| 看调用量 / 报错 | 云开发控制台 → 云函数 → 运行日志（按 `error` 过滤）+ 监控 |
| 交费曲线 | 云开发控制台 → 概览 → 用量/账单，警惕突增 |
| 数据库备份 | 数据库 → 集合 → 导出（JSON/CSV），建议每周导出一次 |
| 云函数版本回滚 | 云函数 → 该函数 → 版本 → 选择上一个版本「切换」 |

## 10. 常见问题排查表
| 现象 | 原因 / 解法 |
|---|---|
| `callFunction fail` / `-501000` | 环境 ID 不对或云开发未开通 → 检查 `app.js` 的 `wx.cloud.init` |
| `FunctionName not found` | 云函数没传上去/名字拼错 → 重新上传 |
| `collection not exists` | 集合没建 → 按第 3 步创建 |
| AI 无回复但求助兜底正常 | LLM Key/BaseURL/Model 不对 → 检查 aiChat 环境变量后重启 |
| AI 回复超时 | 模型慢 → `aiChat/index.js` 云函数配置里的 timeout 调到 ≥ 20s |
| `auth denied` | 数据库手动操作越权 → 权限改「仅创建者可读写」 |
| 登录拿不到 openid | 体验版必须用真 AppID + 预览；基础库版本更新 |
| 审核驳回「功能页无实质内容」 | 保证真机 3 条路径可跑 + 内容完善后再传 |

## 11. 成本预算（量级参考）
- 学生个人演示 / 大赛现场：免费额度基本够
- 每请求大模型 token 成本极低（约 0.1~1 厘 RMB/轮），1 个月千次使用远低于 1 元
- 想控成本：`prompt.js` 已限制回复 max_tokens，应急可再调低
