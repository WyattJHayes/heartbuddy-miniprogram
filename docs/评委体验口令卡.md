# 评委体验口令卡（3 分钟走 3 条路径）

> 用途：答辩/路演前，评委（或你自己）拿一台**新手机**扫码进体验版，照这个口令 3 分钟把核心价值走完。
> 原理：新账号 → 隐私弹窗 → 静默登录 → 每条路径只有一个「动作 + 一句话」，谁拿都能自己跑通。

---

## ⏱ 开始前（演示者 5 分钟准备）
- [ ] 云函数 3 个已部署（`aiChat` 有 `LLM_*` 环境变量，`opsSummary` 白名单含你的 openid）
- [ ] 体验版二维码已生成（开发者工具 → 上传 + 预览/生成体验版二维码）
- [ ] 手机飞行模式关、音量开（演示音效/若需）
- [ ] 网络稳定；真机缓存清过一次（确保走完整注册流）

## 👣 体验路径一：共情对话（60 秒）——「它会说话」
1. 扫码进入 → 隐私弹窗点「同意」→ 自动进「陪伴」页
2. 点底部 **⚡快捷** 里「最近压力好大」或直接打字说：
   > 「我最近压力好大，有点坚持不住了」
3. 观察：AI 共情回复 + 打字机效果；**情绪标签**被自动识别（页面上方出现标签）
4. （如果评委想试试英文）点空态里绿色英文句：
   > "I've been so anxious lately…"
   → 看它**用英文继续陪你**（语言自适应）

**评委看重**：不像机器人、会共情、中英都接得住。

## 👑 体验路径二：危急时刻（60 秒）——「最后一层防线」
1. 仍在对话里，点英语角最下面红色那排（或手打）：
   > "I feel like I can't cope right now"
2. 看三层反应：AI 首先**不评判** → 出现「求助」引导 → 弹窗给**全国心理援助热线**
3. 进入「求助」页：一键电话按钮、危机应对流程图（长按可保存）
4. 打开「运营看板」（我的 → 运营看板）：看是否出现一条**未处理高危**

**评委看到**：这是「AI 安全网」不是广告位 —— 危机永远交给真人/热线。

## 👑 体验路径三：数据质感（60 秒）——「它是你的镜子」
1. 「心情」页：看**最近 7 天心情曲线**（Canvas 折线）+ 心情分布条形图
2. 做一次「考前焦虑自评」（7 题约 2 分钟）→ 拿结果 + 一键**查看本周周报** → 分享卡（浅色/深色双模板）
3. 「我的」页：看**数据与隐私**（自评次数/危机提醒/情绪记录/倾诉次数）
4. 随意发一条留言 → 收到「谢谢你」

**评委看到**：情绪可视 → 报告 → 分享闭环，落地可感知。
