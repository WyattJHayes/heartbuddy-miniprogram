## 一、报名与材料

- [ ] 确认报名成功（官方 https://competehub.dev/zh/ · 以官方公告为准）
- [ ] 组别确认：双人组 / 全能组（本项目按全能组单人亦可）

## 二、代码与功能

- [ ] `project.config.json` 的 **appid** 已替换为真实 AppID
- [ ] 三个云函数（`login` / `aiChat` / `opsSummary`）均已「上传并部署：云端安装依赖」
- [ ] 数据库中已创建：`users / moods / assessments / crisisAlerts / feedbacks`，权限均为「仅创建者可读写」
- [ ] 大模型 Key 走**环境变量**（`LLM_API_KEY`），代码中无明文密钥
- [ ] 隐私同意页可用；不同意时 tabs 可看但不可聊（如配有守卫逻辑）
- [ ] 危机闭环可演示：AI 识别 → 分级（high 弹窗跳求助 → `crisisAlerts` 落库）
- [ ] 测评模块可完成：7 题 → 结果 → 建议 → 进入 AI 对话后有上下文衔接

## 三、演示视频（2 分 40 秒）

- [ ] 时长 ≤ 2:40；真人配音/字幕同步
- [ ] 覆盖：开场痛点 → AI 对话 → 情绪可视化 → 危机安全 → 收尾价值
- [ ] 高危情节用**中性表达**（如「我好像坚持不下去了」），不出现真实高危词汇
- [ ] BGM 有版权（或免版权）；片头/片尾含作品名与 AppID 代码
- [ ] 结尾放置二维码/落地页；注明「AI 情绪陪伴，非医疗诊断」

## 四、合规与隐私（评审容易扣分项）

- [ ] 全站无「诊断 / 治疗 / 心理咨询机构」等医疗属性表述
- [ ] 有《隐私政策》入口（可在“我的”页展示弹窗，或独立页面）
- [ ] 不强制收集微信昵称/头像/位置；敏感字段（对话内容）不进数据库
- [ ] 危机页面有官方热线，且**上线前逐一拨打复核**（12356 / 400-161-9995 等）
- [ ] 若引用开源组件：README 注明协议；量表明细不使用版权量表

## 五、鲁棒性 & 观感

- [ ] 无网络时给出空态/重试，不白屏
- [ ] 打字机效果在慢机不卡顿（已做间隔节流）
- [ ] 全局 UI 统一：色板（主色 #5B8DEF / 中性 #9CA3AF）、圆角、间距
- [ ] 空数据、加载中的占位页齐全（心情空态 / 周报空态 / 看板空态）
- [ ] 真机（至少一台 iOS + 一台 Android 或微信开发者工具真机调试）全流程跑过一遍
